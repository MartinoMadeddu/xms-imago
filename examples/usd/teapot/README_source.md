# Teapot

From the USD Working Group's assets repository, https://github.com/usd-wg/assets (`full_assets/Teapot`), licence **Public Domain, CC0** (see `README.md`, the asset's own). The Fancy Teapot is from PolyHaven's Tea Set by James Ray Cook, Jurita Burger and Rico Cilliers, CC0.

The preview cards, screenshots and thumbnails of the original folder are left out; `Teapot.usd` still names the cards in its draw-mode metadata, which the program does not read.

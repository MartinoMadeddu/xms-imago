# Environment images

| File | Content |
|---|---|
| `sky.hdr` | A sky for dome lights, 256 by 128, latitude-longitude (Radiance HDR): a blue zenith, a warm horizon, dark ground, and a sun 35 degrees up. Made for the program by `make_sky.py` |

To make it again: `python3 make_sky.py sky.hdr`.

A dome light's 📂 browses for your own (EXR, HDR); Poly Haven
(https://polyhaven.com/hdris) has many under CC0.

# Novasci motion pack

Four of the 21 clips of **FreeMotionPack1** by J. Beardmore (Novasci), from
https://github.com/J-Beardmore/FreeMotionPack1, released under CC0 1.0 (public
domain; `LICENSE`).

| File | Frames | Rate |
|---|---|---|
| `ComeHere1.fbx` | 93 | 30 fps |
| `HandsOnHead.fbx` | 135 | 30 fps |
| `Celebrate1.fbx` | 75 | 30 fps |
| `GoAwayAngry.fbx` | 125 | 30 fps |

Skeleton only, no mesh: 66 joints on the Mixamo armature, so Characterize reads
them as Mixamo. Frame 1 is a T-pose. The other 17 clips of the pack are
downloaded by the program when a template asks for one (see `src/examples.rs`,
`SOURCES`).

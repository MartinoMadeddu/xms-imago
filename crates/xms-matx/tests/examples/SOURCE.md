# MaterialX example materials

The example materials of MaterialX, copied unchanged (the `.mtlx` files only,
not their images) from
https://github.com/AcademySoftwareFoundation/MaterialX/tree/main/resources/Materials/Examples
at the same commit as `libraries/` (7a4f557, MaterialX 1.39). Apache 2.0, as
`libraries/LICENSE`. Copyright Contributors to the MaterialX Project.

`tests/examples.rs` imports every one of them.

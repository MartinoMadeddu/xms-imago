# XMS documentation

- [Interface](interface.md): dockable panes, saved layout, theme, primitive inspector, the file browser (sequences, UDIM), wires and selection in every graph, data type colours
- [Undo](undo.md): what is undone, steps, branches, the History pane
- [Templates and example files](templates.md): ready-made graphs for every area of the program
- [Edit Poly](edit-poly.md): polygon modelling in one node
- [UV](uv.md): unwrapping, island editing, the UV Editor pane
- [USD](usd.md): composed stages, primitives and instancing, the Scene Explorer and the Viewer, Write USD
- [ICE graphs](ice.md): Get Data, Set Data and maths run by the ICE Execution Ports over every point, face or corner, compiled and run in parallel
- [MaterialX](materialx.md): the MaterialX node library and the MaterialX operator
- [Rendering](render.md): Render Commons, Render Settings (Karma, Arnold, Custom, renderer definition files, AOVs), Render Variables, as UsdRender prims Write USD writes
- [Geometry](geometry.md): how geometry is held and passed between nodes, and how edits are found. For anyone writing a node
- [Viewer navigation](navigation.md): the seven navigation styles, framing keys
- [Animation and mocap](mocap.md): clips, the timeline, batch export to FBX
- [Keys and the Graph Editor](keys.md): keying any operator's numbers, the scene's range on the timeline, curves, tangents and infinity, Local Animation and Merge Animation
- [Body Collide](body-collide.md): keeping a captured character out of a set and out of itself
- [Builds and releases](releases.md): where the binaries come from

How the program should work and why is in [DESIGN_PHILOSOPHY.md](../DESIGN_PHILOSOPHY.md), at the root of the repository; the operators it has and plans in [XMS_CORE_OPS_SPEC.md](../XMS_CORE_OPS_SPEC.md). How to work on it with an AI assistant is in [LLM_instructions.md](../LLM_instructions.md).
